# ADR KXC-0002: P-256 / ES256 Only for v1

## Status

Accepted

## Context

RFC 9449 allows multiple asymmetric algorithms. Keylix (the Rust reference) restricts v0.1 to ES256/P-256. Mobile platforms have varying support for other curves/algorithms, and expanding the algorithm surface increases the attack area.

## Decision

Keylix Client v1 supports only ES256 (ECDSA with P-256 curve and SHA-256). No RSA, no EdDSA, no other curves.

## Consequences

- Positive: matches Keylix Rust profile; proof interop is guaranteed.
- Positive: P-256 is universally supported by Secure Enclave, AndroidKeyStore, WebCrypto.
- Negative: future post-quantum algorithms are deferred.
- Negative: ecosystems requiring other algorithms (e.g., some FIDO2 deployments) are not directly compatible.
